# Bank Management System (C++)

A console-based banking application built with Object-Oriented Programming
and file handling in C++.

## Features
- Create Savings and Current accounts
- Deposit and withdraw money with rule-based validation
- Balance enquiry with PIN authentication
- Update account details / change PIN
- Close (delete) an account
- Persistent storage in `accounts.txt`

## OOP Concepts Used
- Encapsulation, Abstraction, Inheritance, Polymorphism, Composition

## Build & Run

```bash
g++ BankManagementSystem.cpp -o bank
./bank
